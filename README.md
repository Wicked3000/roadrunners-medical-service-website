# Roadrunners Medical Services

Roadrunners Medical Services is a professional medical consultancy website providing high-quality healthcare solutions and services.

## Features

- **High-impact Professional Branding**: Integrated official assets and premium color-coded CARE framework cards.
- **Advanced Backend Architecture**: Direct Supabase database integration for real-time inquiry logging.
- **Micro-Interaction UI**: Automated form life-cycles with smooth transitions, progress bars, and intelligent success/error diagnostics.
- **"Living" Contact System**: Success confirmation with automatic 3.5s reset and "Send Another" logic.
- **Regulatory Readiness**: Built-in compliance badges and accessible legal framework in the footer.
- **Optimized Performance**: Parallelized backend requests and lightweight vanilla JavaScript implementation.

## Technologies Used

- HTML5 & CSS3 (Vanilla)
- JavaScript (Modern ES6+)
- Supabase (Backend Database & Storage)
- Google Fonts Integration

## Project Structure

- `index.html`: Home page
- `about.html`: About the company, mission, and vision
- `services.html`: Detailed list of medical services
- `team.html`: Profiles of the medical team
- `contact.html`: Contact information and dynamic map
- `/css`: Stylesheets and animations
- `/js`: Logic and interactivity
- `/assets`: Images and icons
